# Expo demo

An Expo app with a tab per use case of `react-native-next-wheel-picker`:

- **Time**: hours and minutes with infinite scroll.
- **Strings**: a union of string literals.
- **Objects**: object values matched by id with `keyExtractor`.
- **Styled**: dark theme, a tinted selection band and bold rows.

Every tab has buttons that set the value from outside.

The app runs the library from `../src` and links its native code from the repo root
(`metro.config.js` and `react-native.config.js`), so library edits show up on reload. In Expo Go it
runs too, with the picker's JS wheel; a development build shows the native one.

```sh
npm install
npm run ios       # npx expo run:ios
npm run android   # npx expo run:android
```

The same app runs on the web with the picker's JS fallback and is published to
[GitHub Pages](https://devmaxxx.github.io/react-native-next-wheel-picker/): `npm run web` to work on
it, `npm run build:web` to export it. On wide screens it shows inside a phone next to a short
pitch (`WebFrame.tsx`).

`ios/` and `android/` are generated by the run commands and are not committed.
